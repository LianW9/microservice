Team 3- Kafka and Walmart

  I thought it was interesting how Micheal used the sponge analogy to explain how and why the data needs to be processed using Kafka. Thinking of the data as a flow and Kafka as a sponge to intake buffer and distribute the data helped me to better understand not only how the process worked but also why processing the data in bytes was not only the best solution but also how creative it was. The need for real time information on a scale the size of Walmart’s was never a problem I had considered before this presentation.
